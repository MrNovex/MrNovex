## 🏍️ Featured Project — Moto Travel Planner

> Mein bisher größtes **End-to-End-Projekt** – ein kompletter Motorrad-Tourenplaner, den ich **konzipiert, zusammengeführt und selbst in Betrieb genommen** habe.

Eine Android-App, die aus Start, Ziel und ein paar Wünschen in Sekunden eine fertige Route mit Etappen, Stopps, Karte und GPX-Export plant. Dahinter: ein eigenes Backend und eine selbst gebaute, kurvige Routing-Engine auf OpenStreetMap-Basis – komplett auf eigenem Linux-Server gehostet.
